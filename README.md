### Sobre

Aulas e exercícios de Front-End do 1º ano de Engenharia de Software na FIAP, em ordem, do primeiro HTML até o checkpoint final.

<br>

### Conteúdo

| Pasta | Tema |
|:---|:---|
| [`01-introducao-html-css`](./01-introducao-html-css) | Primeira página, links, imagens e vídeo |
| [`02-divs`](./02-divs) | Organização do layout com blocos |
| [`03-flexbox`](./03-flexbox) | Alinhamento com Flexbox |
| [`04-exercicio-flexbox`](./04-exercicio-flexbox) | Exercício de layout com Flexbox a partir de um protótipo |
| [`05-revisao-media-queries`](./05-revisao-media-queries) | Revisão e primeiras media queries |
| [`06-media-queries`](./06-media-queries) | Site responsivo a partir de um layout |
| [`07-exercicio-responsividade`](./07-exercicio-responsividade) | Exercício de responsividade com fontes próprias |
| [`08-bootstrap`](./08-bootstrap) | Componentes do Bootstrap e introdução ao JavaScript |
| [`09-animacoes`](./09-animacoes) | Transições e `@keyframes` |
| [`10-exercicio-animacao`](./10-exercicio-animacao) | Exercício de animação com JavaScript |
| [`11-pokedex-checkpoint`](./11-pokedex-checkpoint) | **Checkpoint 5:** Pokédex com filtros, modal e criador de cartas |
