### Sobre o projeto

Site temático de Pokémon feito como avaliação prática (Checkpoint 5) de Front-End na FIAP, com HTML, CSS e JavaScript.

<br>

<div align="center">
  <img src="images/global/banner-full.png" width="70%" />
</div>

<br>

### Funcionalidades

- Cards de Pokémon gerados a partir de dados em JavaScript
- Filtro por tipo: água, fogo, planta, elétrico, gelo, normal e psíquico
- Modal com altura, peso, habilidades, fraquezas e evoluções
- Formulário que cria uma carta especial personalizada
- Seção de integrantes no estilo "escolha seu personagem"
- Layout responsivo
